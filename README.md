# Nomoo

A simple public-facing student book marketplace landing page for the SEDSIS/СЭЗИС student community.

## Run locally

From the project root:

```bash
python3 -m http.server 3000
```

Then open http://localhost:3000 in your browser.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — small UI enhancement to populate the footer year
